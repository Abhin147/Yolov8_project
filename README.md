# YOLO Image Object Detection

A simple computer vision project using YOLOv8 and OpenCV to detect objects in an image.

## Features

- Detects objects using YOLOv8
- Draws bounding boxes around detected objects
- Displays object names and confidence scores
- Saves the resulting image

## Technologies

- Python
- OpenCV
- Ultralytics YOLOv8
